# Solicitações
Um gerenciador de tarefas desenvolvido com React, criado com o objetivo de praticar conceitos fundamentais da biblioteca, como componentes, estados, eventos e manipulação de listas.
Funcionalidades:
- Adicionar novas tarefas
- Marcar tarefas como concluídas
- Excluir tarefas
- Filtrar tarefas por status
